# Stack8Tools

A collection of small developer tools that I built to make common development tasks a little easier.

Stack8Tools brings different utilities into one place, so you don't have to open a separate website every time you need to format JSON, test a regex, check a color, test an API, optimize an image, or generate a UUID.

Most of the tools work directly in the browser, so there is no need for a backend for the core functionality.


***What You Can Do With Stack8Tools***

The project currently has 12 tools:

1.JSON Formatter – Format, validate, minify, copy, and download JSON.

2.Regex Tester – Test regular expressions and check matches in your text.

3.Color Picker – Work with HEX, RGB, and HSL colors and generate random colors.

4.Text Editor – Edit text, change case, reverse text, search and replace, and check word/character counts.

5.Code Snippets – Browse and search useful code snippets and copy them quickly.

6.Unit Converter – Convert length, time, file size, and color values.

7.CDN Finder – Find CDN links for commonly used libraries.

8.Code Preview – Write HTML, CSS, and JavaScript and see the result in the browser.

9.Image Optimizer – Resize, compress, and convert images directly in the browser.

10.Documentation Hub – Find quick links to documentation for popular developer technologies.

11.API Playground – Send HTTP requests and view the response without leaving the tool.

12.UUID Generator – Generate UUIDs and other useful random identifiers.
